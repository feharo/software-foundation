# Decisão pendente: licença de distribuição

O repositório está privado e **não possui uma licença pública definida**. Antes de permitir que qualquer pessoa clone, modifique, distribua e use o código comercialmente, o proprietário deve escolher a licença e adicioná-la como `LICENSE`.

| Opção | Consequência geral |
|---|---|
| MIT | Permissiva e simples; permite uso comercial e código fechado sob condições de preservação de avisos |
| Apache-2.0 | Permissiva, inclui termos explícitos de patente e notificações |
| GPLv3 | Copyleft na distribuição de software derivado |
| AGPLv3 | Copyleft mais abrangente em cenários de uso via rede |

Não substitui orientação jurídica. Verificar titularidade do código e dependências de terceiros. **Nenhuma licença foi escolhida automaticamente.**

Até a decisão, indicar explicitamente no README que o projeto é experimental e permanece com direitos reservados.
