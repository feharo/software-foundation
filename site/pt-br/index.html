01 · Criar

Comece um SaaS com estrutura

Gere um projeto Next.js/React com Supabase Auth/PostgreSQL ou PostgreSQL independente e Better Auth.

python3 foundation.py init \
  --name "Meu SaaS" \
  --database postgres
Como instalar e configurar
02 · Evoluir

Adote padrões sem destruir seu código

Faça uma prévia da adoção e gere auditorias estáticas, sem reescrever automaticamente o código-fonte.

python3 foundation.py adopt ../projeto
python3 foundation.py audit ../projeto \
  --format markdown

O que está incluído

Práticas de engenharia para desenvolvimento com IA.

31 regras de performance

Orientações versionadas de frontend, dados, cache, renderização e observabilidade.

Documentação para agentes

Escolha do banco

Limitações transparentes

Sem métricas falsas ou promessas de produção pronta. O que não foi medido continua não verificado.

Perguntas frequentes

Saiba exatamente o que está incluído.

Posso usar meu PostgreSQL?

Sim. O perfil independente suporta Docker, VPS ou banco gerenciado, sem depender do Supabase.

A ferramenta corrige problemas automaticamente?

Não. A auditoria é estática: não executa benchmarks de produção nem reescreve código.

O SaaS gerado está pronto para produção?

Não. Configure autenticação, dados, backups, e-mail, segurança e requisitos do negócio.

Agentes de IA conseguem utilizar?

Depois da publicação, poderão consultar o guia de escolha e as Skills, sem garantia de recomendação automática.
