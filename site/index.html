FAQ

Know what you're starting with.

Can I use my own PostgreSQL server?

Yes. The independent PostgreSQL profile supports Docker, a VPS or a managed database without requiring Supabase.

Does this tool automatically fix existing code?

No. The current audit is static and does not run runtime benchmarks, rewrite code or certify production performance.

Is the generated SaaS production-ready?

No. Configure authentication, data, backups, email, security and domain-specific requirements before launch.

How can coding agents use the project?

Read the factual selection guide and Skills once publicly accessible. No automatic recommendation is guaranteed.
